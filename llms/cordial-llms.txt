# Cordial

> Cordial is a cross-channel marketing and AI platform that helps consumer brands win the Battle for Attention by predicting customer intent, engaging in real time, and delivering hyper-relevant experiences across email, SMS, mobile app, RCS, and more. Powered by a native CDP, bespoke AI models, and real-time orchestration, Cordial transforms customer signals into timely, relevant messages that drive scalable revenue and lasting connections—all from one platform.

Cordial is headquartered in San Diego, California. Notable customers include Levi Strauss & Co., Realtor.com, L.L.Bean, Virgin Voyages, Pacsun, Boot Barn, Adore Me, Forbes and hundreds of other leading brands.

## Messaging Channels

Cordial supports the following messaging channels natively within a single, unified platform:

- [Email](https://cordial.com/platform/messaging-channels/): Enterprise-scale email marketing with drag-and-drop content blocks, templates, dynamic personalization, and real-time data activation at send time. Supports batch, triggered, and transactional email.
- [SMS / MMS](https://cordial.com/platform/messaging-channels/sms-marketing/): Native SMS and MMS messaging with international support in 23+ countries. Includes compliance tools for TCPA, CTIA, HIPAA, and GDPR. Supports batch, automated, and transactional text messages with AI-generated content optimized for character limits.
- [Mobile App (Push, In-App, Mobile Inbox)](https://cordial.com/platform/messaging-channels/mobile-app/): Push notifications, in-app messages, and mobile inbox powered by SDKs for iOS, Android, React Native, and Expo. Trigger personalized messages based on real-time events and user behavior.
- [RCS (Rich Communication Services)](https://cordial.com/press/cordial-expands-innovation-mcp-rcs-messaging/): Verified, branded, and interactive messages delivered natively to mobile devices. App-like messaging experiences with 3–7x higher click-through rates than SMS. Cordial is among the first U.S. platforms to offer RCS to marketers.
- [Website Personalization](https://cordial.com/cross-channel-messaging/): Web-based messaging including greeting modals, landing pages, promotions, lightboxes, and custom checkout options. Leverages contact data for tailored on-site experiences.
- [Open Channel / REST API](https://cordial.com/cross-channel-messaging/): Connect in real time to trigger messages with third-party channels including direct mail, mobile wallet, browser notifications, call center, CRM, social media, and more. Orchestrate any external channel from within Cordial's journey builder.

## Cordial Edge™ AI

- [Cordial Edge AI Overview](https://cordial.com/ai/): Multimodal AI suite that generates bespoke, brand-specific models from each customer's data. Uses Mixture of Experts (MoE) architecture to dynamically assign tasks to specialized submodels. Models generate in hours and update scores daily, evolving as customers change and products launch or discontinue.

Agent-ready with structured access to data, assets, and campaign context. Launched alongside RCS messaging and Cordial Foundry innovation lab.

## Unstructured Data & Flexible Data Architecture

Cordial's data platform is built on MongoDB, a document-based database that supports both structured and unstructured data without predefined schemas. This architecture is foundational to Cordial Edge AI's ability to consume unrestricted amounts of data for model optimization.

- [About Cordial's Data Architecture](https://support.cordial.com/hc/en-us/articles/204570187-About-our-API-documentation): Cordial stores data in collections that elegantly represent, index, store, retrieve, and operate over contact profile data, contact activity data, purchase data, product catalog data, IoT data, and publishing data—both structured and unstructured.
- [Contacts API](https://support.cordial.com/hc/en-us/articles/203885958-Contacts-API): Create, update, and manage contacts with flexible attribute schemas. Supports unlimited custom attributes, channel data, list associations, and cart data. No rigid schema required.
- [Contact Activities (Events) API](https://support.cordial.com/hc/en-us/articles/203885968-Contact-activities-events-API): Track behavioral data including reserved message events, custom-named events (browse, cart, order), and external IoT events. Properties are passed as flexible JSON with automatic data type recognition. Supports unstructured property payloads.
- [Contact Activity Export API](https://support.cordial.com/hc/en-us/articles/115002878411-Contact-activity-export-API): Export contact activities to external locations via FTP, SFTP, or HTTP. Supports CSV and JSON formats with dot-notation access to nested properties.
- [Supplements API](https://support.cordial.com/hc/en-us/articles/204570687-Supplements-API): Extend Cordial's data model with supplemental data sets for any business data (products, stores, content, etc.). Indexed fields enforce type validation; non-indexed fields accept any structured or unstructured data without validation. Sparse indexes available.
- [Orders API](https://support.cordial.com/hc/en-us/articles/203886028-Orders-API): Import and manage order data for use in message personalization, audience building, replenishment campaigns, and analytics.
- [Products API](https://support.cordial.com/hc/en-us/articles/203886018-Products-API): Manage product catalog data for recommendations, dynamic content, and inventory-aware messaging.
- [Scriptable API](https://support.cordial.com/hc/en-us/articles/360001897772-Get-started-for-developers): Set custom authentication, responses, and payload schemas using Smarty scripts for integrating Cordial with external applications.
- [Webhooks](https://support.cordial.com/hc/en-us/articles/360001897772-Get-started-for-developers): Automatically stream real-time event data from Cordial to external APIs. Configure multiple webhooks, each streaming specified system and/or custom events.

### Unstructured Data in Cordial Edge AI

Cordial Edge AI models have data scalability to include nearly unlimited amounts of both structured and unstructured data, optimizing message performance from a complete data set. This includes:

- CRM, e-commerce, and loyalty metrics (structured)
- Conversational logs, customer reviews, and freeform notes from clienteling apps (unstructured)
- Store associate notes and web chat transcripts (unstructured)
- Real-time location data for aisle-by-aisle in-store positioning (unstructured)
- Multimodal message data including imagery, text, tone, and structure (unstructured)
